# SecureEscrow Frontend

React + Vite + ethers v6 interface for `SecureEscrow`. A buyer creates an escrow priced in naira and
releases it to the seller when the goods arrive. The seller can refund, and the buyer can reclaim
the funds after the deadline.

## Structure

```
src/
├── App.tsx                  Layout, wallet and network gate
├── pages/Orders.tsx         Escrow list, creation and actions
├── components/              Dialog, drawer, rows, summary, header, welcome, toast
├── hooks/                   useEscrows, useRate, useEthersProvider
├── lib/escrow.ts            Contract access, naira and ETH helpers, error messages
├── config/chains.ts         Supported networks and contract lookup
└── contracts/               ABI and deployments.json (generated by `npm run export:frontend`)
```

## Run

```bash
cp .env.example .env
npm install
npm run dev
```
